Wynfall is private AI for writing, decisions and code. Sigel is our own model, and it runs in the browser, on Windows, in the terminal, and on your own machine.

This repository is the public half of that work. It holds what we release and when, in plain language.



## Corrections are welcome

If a release note describes something that does not match what the app actually does, that is a bug in the note and worth an issue. So is a typo, a broken link, or a sentence that assumes knowledge a reader does not have.

Documentation fixes are the easiest way to contribute, and they are genuinely useful. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Stay current

Watch this repository (Watch, then Custom, then Releases) to be told when a version lands.
